# 티스토리

**제목:** 목소리 복제 오디오북 제작기 - 30분에 4센트, 측정으로 증명한 하이브리드 구성

**요약:** 클라우드 전량 사용 2.85달러, 무료 로컬 모델과 조합 4센트. 같은 원고, 같은 목소리, 같은 결과물. 실제 청구서와 측정값으로 정리한 제작 기록입니다.

## 들어가며

음성 합성 비용은 글자 수로 결정됩니다. 그래서 "싸게 만드는 법"은 모델을 바꾸는 일이 아니라 **어떤 문단을 어느 엔진에 보낼지 나누는 일**입니다.

이 글은 30분 분량 오디오북 한 권을 실제로 완성하면서 남긴 기록입니다.

## 결과 요약

| 항목 | 전량 클라우드 | 하이브리드 | 로컬 단독 |
|---|---|---|---|
| 크레딧 | 17,200 | 229 | 0 |
| 비용 | 약 $2.85 | 약 $0.04 | $0.00 |
| 연산 시간 | 없음 | 76분 | 76분 |
| 한국어 | 가능 | 가능 | 다국어 모델 필요 |

## 구조

- 원고: 9개 장, 22,960자
- 출력: 30분 13초, 48kHz, 피크 -1.0dBFS, 결함 0건
- 엔진: 로컬 LuxTTS(영어) + 클라우드 복제(한국어)

## 엔지니어링 포인트 세 가지

**1. 모델이 견디는 크기로 자르기.** 작은 로컬 모델은 CPU에서 800자 근처에서 무너집니다. 그래서 문장 단위로 400자까지만 자르고, 이음새는 50ms 크로스페이드로 붙입니다.

**2. 렌더마다 측정.** 클리핑, 음량 이탈, 무음 패딩, 이음새 클릭, 길이 이탈 등 여섯 가지 결함을 자동 판정하고 최근 200건에 대한 관리도를 유지합니다. 편집 단계에서 문제를 발견하는 대신 렌더 직후에 걸러집니다.

**3. 목소리와 엔진의 계약.** 목소리마다 발화 가능한 엔진이 묶여 있어서, 클라우드 목소리 ID가 로컬 모델로 전달되는 사고가 구조적으로 불가능합니다. 프로젝트 초반의 혼란스러운 오류 하나가 이렇게 사라졌습니다.

## 명령 세 줄

```
python3 tools/audiobook.py --script book.md --engine voicebox --voice local --all --stitch
python3 tools/english_edition.py --book audiobooks/en-only --render-stings
python3 tools/upload_english_edition.py 5
```

장 렌더링, 에피소드 패키징, 초안 업로드까지 세 줄입니다.
